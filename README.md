# Currency Converter 💱

A simple currency converter web application that converts one currency into another using live exchange rates.

## Features

- Convert different currencies
- Live exchange rates using an API
- Swap currencies
- Simple and responsive design
- Input validation
- Beginner-friendly JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- Exchange Rate API

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enter an amount.
4. Select the currencies.
5. Click the Convert button.
